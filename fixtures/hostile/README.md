# Hostile docs corpus (ticket 19)

Markdown only, nothing executable. Every file under `docs/` is written the way a hostile cloned repo
could write it: HTML and SVG payloads, Mermaid directive and `click` tricks, every URI scheme, UNC,
`file:`, ADS, device-name, 8.3 and `..` image and link targets, RTL and homoglyph labels, frontmatter
bombs and deep nesting. The "beacon" hosts are `evil.example` (reserved, RFC 2606) and `\\evil\share`,
so nothing here can reach a real machine even if a check fails.

Open it with `npx folio-viewer --docs fixtures/hostile` (or `task web -- --docs fixtures/hostile`) and
watch the network: the only requests must be to `127.0.0.1:<port>`.

`frontend/src/lib/render/hostile.test.ts` renders every file here through the real pipeline (parser,
markdown-it, the sanitiser) in happy-dom and asserts that no element or attribute outside the allowlist
survives and that no URL outside `#`, `/doc/...` and validated http(s) is produced. The fuzz tests in
`frontend/src/lib/render/fuzz.test.ts` and `frontend/src/server/fuzz.test.ts` generate more of the same.

Not in the corpus because git cannot carry them portably: symlinks and junctions (the server tests make
real ones in a temp folder when the OS allows it), files over the 5 MB cap and folders hundreds deep
(generated by the tests), and real NTFS alternate data streams.

| File | What it tries |
|---|---|
| `01-html-svg.md` | raw HTML, inline SVG, event handlers, `<meta refresh>`, `<base>`, `<link>`, forms, mXSS shapes, entity-encoded `javascript:` |
| `02-mermaid.md` | `click` (callback, href, `javascript:`), `%%{init}%%` (securityLevel, themeCSS, themeVariables, htmlLabels, dompurifyConfig, fontFamily), frontmatter `config:`, HTML in labels, `classDef`/`style` with `url()`, sequence `link`/`links` |
| `03-schemes.md` | every URI scheme as a link, autolink and bare text |
| `04-paths.md` | image and link targets: UNC, `file:`, drive letters, ADS, device names, 8.3 names, `..` and encoded `..` |
| `05-labels.md` | RTL override, homoglyphs, zero-width characters, a label that shows another URL |
| `06-frontmatter-bomb.md` | prototype keys, many keys, a long value, unclosed quotes and brackets |
| `07-nesting.md` | thousands of nested blockquotes, lists and emphasis |
| `08-escape-links.md` | relative links and refs that try to leave the docs root, and links to `__proto__` / `constructor` |
