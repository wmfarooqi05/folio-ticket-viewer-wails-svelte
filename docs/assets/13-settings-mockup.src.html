Context

Today four cron jobs nudge cash between accounts, each with its own idea of a cut-off. This ticket builds one service — the cash mover — that prepares a single instruction per transfer and hands it off. Who actually releases the money is settled in map.md#Q3.

tscopy
export async function moveCash(day: BusinessDay) {
  const due = await transfers.dueBefore(cutoff.of(day));
  for (const t of due) {
    // AC1: same transfer, same file, every time
    await instructions.write(t, { idempotencyKey: t.id });
  }
}
